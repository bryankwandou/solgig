THE SOLUTION

Every SolGig product answers HTTP 402 with a price.

Catalog for machines

One JSON endpoint lists every product, price and purchase URL, with a JSON Schema.

SOL or USDC

The 402 lists both, with exact transfers and instructions ready to sign.

Receipt on-chain

The answer carries the transaction signature. Anyone can check the purchase.

No account, no SDK, no API key · 3

The fix is to treat each product as an x402 resource. The catalog tells an agent what exists. The 402 tells it the price in SOL or USDC and exactly what to send. The success response carries a receipt tied to the transaction signature.
