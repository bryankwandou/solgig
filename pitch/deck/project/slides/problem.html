THE PROBLEM

Agents can pay now. They have nowhere to shop.

No card, no bank

An agent cannot pass KYC or a card check. It can sign a Solana transaction.

Rails, not shelves

x402 tools on Solana charge for API calls. None of them list goods from many sellers.

Stores assume a browser

Checkout pages, cookies and captchas block a buyer that is a script.

Source: Colosseum Copilot project search, 26 Sep 2026 · 2

Agents already hold wallets and can pay. What they lack is somewhere to buy things. On Solana, the x402 projects we found are payment rails for API calls. None of them is a catalog of goods from many sellers. And ordinary stores are built for a person in a browser.
